# TasteSift MVP 1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan inline, then one independent whole-branch review.

**Goal:** Deliver the five approved improvements on the existing private Site.

**Architecture:** Extend the local helper's HTTP response with real progress events. Share a bilingual category catalog across import, editing, filtering and saves. Use R2 for authenticated image storage and a cookie-backed language provider for the recipe interface.

**Tech Stack:** Existing TypeScript, React/Vinext, D1/Drizzle, R2 and Node tests; no new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-11-17-mvp11-design.md`

## Global Constraints

- Preserve private audience, current recipes, source attribution, existing roles and explicit-confirmation saves.
- Keep the existing one-folder/native workflow; do not expand family management or paid services.
- Upload JPEG/PNG/WebP only, maximum 5 MiB, with server-side signature and body-size validation.
- Existing category values remain usable; new names require confirmation and unique normalized aliases.
- Interface translation does not translate source recipe text.

## Review Focus

- Concurrent category creation must reuse one category rather than create duplicate aliases.
- Existing bilingual or differently spaced category names must remain filterable.
- Uploading an invalid file must preserve recipe edits and the previous image.
- Switching language must not discard an unsaved import or edited fields.
- Viewers must not upload/create categories, and non-owners must not access internal test pages.

### Task 1: Real import progress and language foundation

**Files:** `lib/recipes/import-local.ts`, `scripts/facebook-recipe-local.mjs`, `components/recipe-importer.tsx`, `components/import-progress.tsx`, `components/language-provider.tsx`, `lib/i18n.ts`, `lib/language-server.ts`.

**Interfaces:** Import stages are `connecting`, `reading`, `transcribing`, `organizing`, `ready`. The helper streams `{stage}`, `{recipe}` or `{error}` lines; the client tolerates split chunks and the earlier JSON response. A shared language provider exposes `language` and `t` to client components.

### Task 2: Unified category catalog

**Interfaces:** `Category` has `value`, `kind`, `labelZh`, `labelEn`, and `aliases`. `listCategoryCatalog()` reads the current catalog and existing recipe values. `createCategory()` reuses normalized aliases; explicit creation is authorized for editors/owners.
